# Changelog

## 0.2.0 - 2026-10-16

- Added an explicit download Speed Test with 25, 50, 100 and 250 MB payload limits, a real-data confirmation, cancellation and partial results. Test traffic remains included in normal usage totals.
- Added a system tray quick view with live download/upload rates, today's usage and a 60-second traffic graph. Single-click opens the popup, double-click opens the dashboard, and the tray menu includes Settings.
- Added a header VPN key for confirmed active tunnels, including split tunnels, with available connection names in its tooltip.
- Extended the Dashboard live traffic graph to 130 seconds and refined the usage range selector, summary and download/upload colors.
- Improved History daily usage hover outlines and tooltips, including pointer and window lifecycle handling.
- Changed packet loss to display as unavailable when internet reachability succeeds but ICMP receives no replies, with explanatory text and gaps in the chart.
- Set application version metadata to 0.2.0.

## 0.1.0

- Initial GitHub release, tagged `v0.1.0-alpha`, with the Dashboard, Connections, Health, App Usage and History views.
